Privacy Policy — Pantau War Tiket

Last updated: 12 November 2026

Pantau War Tiket ("the App") is a small, private social-listening tool operated by a single individual (the "Operator"). It uses the official Threads API from Meta to search public Threads posts that contain specific keywords related to concert ticket purchasing services (for example "jasa war tiket"), and forwards the matching posts to the Operator's own private Telegram chat. The App is not offered to the public and has no sign-up.

1. Information the App accesses

  • Operator's Threads account (via threads_basic): the Operator's own Threads user ID and username, needed only to authenticate API requests.
  • Public Threads posts (via threads_keyword_search): for posts that publicly match the configured keywords, the App receives the post ID, text, author username, permalink and timestamp, exactly as returned by the Threads API.

The App does not access private messages, follower lists, passwords, contact details, location, or any data that is not publicly available through the Threads API.

2. How the information is used

  • Matching posts are labelled automatically with simple keyword rules (for example "looking for a service" or "offering a service") and sent as a notification to the Operator's private Telegram chat, so the Operator can read them and, if appropriate, reply manually on Threads.
  • The App never posts, replies, likes, follows or sends messages automatically on Threads.
  • The data is not sold, rented, shared with advertisers, or used to build profiles of individuals.

3. Storage and retention

  • The App stores only post IDs (a list of up to 5,000 most recent IDs) to avoid sending the same post twice. Post text is not stored by the App; it exists only inside the Telegram notification.
  • Access tokens are stored encrypted as GitHub Actions secrets and are never published.
  • The App runs on GitHub Actions; data is transmitted only between the Threads API, GitHub and Telegram over HTTPS.

4. Third-party services

The App relies on: Meta Threads API (data source), GitHub Actions (scheduling/runtime) and Telegram Bot API (notifications to the Operator). Each service processes data under its own privacy policy.

5. Data deletion instructions

You can have your data removed in any of the following ways:

  • If you authorized the App with your Threads account: open Threads → Settings → Account → Website permissions → Active, select Pantau War Tiket and tap Remove. This revokes the App's access immediately.
  • If one of your public posts was matched: email the Operator at the address below with the post link. The post ID will be deleted from the App's records within 30 days, and the App will not process it again.
  • Deleting a post on Threads also removes it from future search results automatically.

6. Children

The App is not directed at children and does not knowingly process data of children under 13.
